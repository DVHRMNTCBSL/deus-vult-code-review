# BLUE MANGO

Obra publica de xadrez com treinador Mango, UX mobile/desktop, temporizador, anuncio de resultado, relatorio pos-partida e resolvedor DV.

Site publico: https://blue-mango-dv.surge.sh/

Este diretorio espelha os artefatos publicados e o motor necessario para auditar o resolvedor local.

## Pacote

- `deus-vult-public/blue-mango.html`: interface principal.
- `deus-vult-public/blue-mango-model.js`: manifesto tecnico e UX.
- `deus-vult-public/scripts/blue-mango-tablebase-proxy.js`: backend local opcional.
- `scripts/dv-chess-algorithm.js`: gerador legal, perft e busca limitada.
- `deus-vult-public/dist-blue-mango/`: build publicado no Surge.
